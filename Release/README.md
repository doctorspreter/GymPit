# Release-Artefakte

`GymPit-1.0-pre-final-id.xcarchive` ist ein veraltetes, nicht signiertes
Prüfarchiv mit der früheren Bundle-ID `app.gympit.training`. Es darf nicht zu
App Store Connect hochgeladen werden und beeinflusst das Xcode-Projekt nicht.

Für App Store Connect muss mit dem Apple-Developer-Account ein neues,
signiertes Archiv mit der finalen Bundle-ID `app.gympit` nach den Schritten in
`../RELEASE.md` erstellt werden.
