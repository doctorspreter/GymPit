# GymPit

GymPit ist eine native Trainings-App für iPhone, iPad und Apple Watch. Das Xcode-Projekt enthält außerdem eine Live Activity für laufende Trainings und eine freiwillige Unterstützung über StoreKit 2.

## Projekt öffnen

`GymPit.xcodeproj` in Xcode öffnen und das gemeinsame Scheme `GymPit` auswählen.

## Voraussetzungen

- Xcode 16 oder neuer
- iOS 18 oder neuer
- watchOS 11 oder neuer
- Apple Developer Team `Q3CD6ZPU9J`

Die releasebezogenen Schritte stehen in [RELEASE.md](RELEASE.md).
